## 会議・社内文化

| 用語 | 意味 |
|---|---|
| 経営会議 | 原則として月2回、火曜の9時〜10時30分に開く。90分を厳守する |
| 宿題 | 社長の差し戻しのこと。必ず「何があれば決められるか」が添えられ、次回までに回答する |
| やらまいか | 社長が承認するときの決め台詞（遠州弁で「やろうじゃないか」）。社内では「やらまいかが出た」が「決裁が下りた」の意味になる |
| 預かり | 社長がその場で決めず、期限を区切って持ち帰ること |
| 潮目日記 | 社長が毎週金曜に更新する社内ブログ（2021年〜） |
| 3.9（さんてんきゅう） | 2024年3月9日のランサムウェア被害の社内呼称。「36時間」とも言う |
| 往復ドア／片道ドア | CTOの口癖。後から戻せる判断が「往復ドア」、戻せない判断が「片道ドア」 |
| 穴熊 | CIOの将棋の比喩。守りを固めてから攻めること |
| 現場デー | ミナトヤ・デジタルのエンジニアが毎週1回、店舗やDCで働く日 |

## 業界・制度（実在の動向）

| 用語 | 意味 |
|---|---|
| 2024年問題 | 2024年4月から、トラックドライバーの時間外労働に年960時間の上限がかかった。これに伴う輸送力の不足 |
